# User Guide

Welcome to the Nexara user guide. Nexara is a self-hosted community platform
for families, clubs, and small groups. You run it on your own hardware, so
your members' posts, photos, and conversations stay under your control.

This section is for the people who install, administer, and use a Nexara
community. If you want to change the code instead, see the
[Developer Guide](../developer/index.md).

## Where to start

- **[Self-Hosting](self-hosting.md)** -- Install Nexara with Docker Compose or
  Helm, configure environment variables, and keep your instance running.
- **[Features](features.md)** -- A tour of posts, events, chat, galleries,
  and subgroups, and how visibility works for each.
- **[FAQ](faq.md)** -- Answers about community setup, privacy, permissions,
  and backups.
